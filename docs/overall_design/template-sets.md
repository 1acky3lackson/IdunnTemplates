# 模板集合及其放置

## 设计

模板可以集结成为集合。集合称为 Template Sets，简称 Sets。集合是一些模板的集合，其来源可以是

* 某文件夹（及其子文件夹中的所有模板）
* 某一个模板

集合可以有多个来源，这些来源间彼此并列，每个来源有其随机选择权重，这个来源添加的所有模板均带有此权重（默认为1）。
当采用集合放置指令（idunn sets place）时，将从集合的所有模板中加权随机一个出来放置。

集合具有一下属性：
* 放置时的旋转：0/90/180/270/random，默认为 0
* 放置时的x翻转：true/false/random，默认为 false
* 放置时的y翻转：true/false/random，默认为 false

集合中的每一条来源具有属性：
* 路径（如果是父文件夹则递归地包括所有的子模板，否则仅表示一个模板）
* 权重（会被所有子模板继承）

集合中的模板具有以下属性：
* 权重（从来源中继承，如果有多个来源则取权重的最大值）

## 实现

集合的内容保存在每个玩家的 preference 中，可以被序列化储存

集合的来源需要以一个来源一个bossbar的形式始终显示给玩家

玩家可以修改当前集合属性（旋转翻转等），并展示给玩家。

集合默认是空集，如果是空集则不展示bossbar。

bossbar应当是
```
=== Sets: 5 templates, rotate: rand, flipx: rand, flipy: rand ===
=== [1] (3 templates) user/Jacky/ === // 1 是权重
=== [3] (1 templates) user/foo/bar ===
=== [1] (1 templates) user/bob/helo ===
```

集合放置的指令需要通过聊天栏告知玩家选择的模板（点击tp到母版）以及是否取消放置（取消的话需要一并删除刚刚创建的实例并撤回放置的we操作）。

/idunn instance place 指令移动到 /idunn template place。并且放置后也要通过聊天栏告知玩家选择的模板（点击tp到母版）以及是否取消放置（取消的话需要一并删除刚刚创建的实例并撤回放置的we操作）。

允许玩家通过指令编辑集合的内容（查看/添加/删除来源条目，删除通过查看打印的聊天栏信息点击实现）。

允许玩家将当前的集合保存为集合预设（需要提供名称），储存在玩家的 preference 中。

允许玩家列出他自己的集合预设。

允许玩家加载他某个集合预设（通过列出集合操作打印的聊天栏信息点击实现）
